# Contributing

Open an issue describing the behavior, the script and source variant involved, your Python and dependency versions, and a minimal example. Keep credentials and participant data out of reports.

For a pull request, keep research-method changes separate from maintenance fixes. Preserve the historical log-density fusion baseline and document any new operator or cache format. Add a focused CPU test for behavior that can be checked without model downloads, and run the release checks in the README before submitting.

Use English comments, docstrings, command help and interface messages. Keep private paths configurable, do not commit generated datasets or weights, and preserve upstream notices when editing licensed code. Credit both project collaborators and any other contributors whose work is used.
